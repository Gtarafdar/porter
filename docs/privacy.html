Privacy

Porter is local-first. There is no Porter cloud account and no Porter analytics backend that receives your file contents.

  • Config and activity live under ~/.porter/ on your Mac.
  • File transfer happens between your Macs over LAN, Tailscale, or an optional tunnel you start.
  • GitHub is used for releases and optional update checks. You may save a personal access token locally for rate limits.
  • Tailscale is a separate product you install. Its privacy practices are Tailscale’s.

This site is static on GitHub Pages. It may call the public GitHub API in your browser to show the latest release and changelog.
