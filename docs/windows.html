Porter on Windows

Separate Setup EXE for Windows x64. Same Finder UI, pair token, and Tailscale mesh as Mac — without changing the Mac DMG or Travel Ready path.

Download Setup EXE Mac + Windows downloads All releases

Install

  1. Download Porter-Setup-0.2.35-windows-x64.exe
  2. Run Setup → allow UAC
  3. Installs to C:\Program Files\Porter
  4. Open Porter from the Start Menu
  5. Optional: allow the Private firewall rule for TCP 47831

Mac users: keep v0.2.34 DMG — the Windows tag is not a Mac release. GitHub Latest stays Mac.

First use

  1. Set the same pair token as your Mac(s)
  2. Install Tailscale for Windows (same account)
  3. Add PC / Add Mac → paste the other computer’s Tailscale 100.x address + port 47831
  4. Share folders (enable write to receive copies)

SmartScreen

Porter is MIT and not Microsoft-signed yet. Windows may show “Windows protected your PC”. Choose More info → Run anyway. Same class of warning as Mac Gatekeeper for unsigned indie apps. Prefer downloads only from official GitHub Releases.

Limits (v1)

  • x64 Windows first (ARM later)
  • Full Travel Ready / Set & forget remains strongest on Mac home; Windows can install a login Task Scheduler task via Set & forget
  • Chrome Library helpers are macOS-only for now
  • Prefer Tailscale over Cloudflare for travel
  • Mac↔Windows and Windows↔Windows both work with the same pair token
